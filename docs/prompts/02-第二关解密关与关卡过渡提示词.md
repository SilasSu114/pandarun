## 第一关到第二关的过渡

当前第一关在玩家接触出口后会把 `level_complete` 设为 `true` 并停住。请把这个结束状态改成短暂的过渡流程：

1. 玩家接触激活出口后，先让出口变色或做一个简单的视觉结算反馈。
2. 禁止玩家继续移动和跳跃。
3. 使用一个短促的全屏过渡，例如黑场淡入淡出。
4. 过渡结束后加载第二关场景。
5. 过渡期间不要显示任何文字，例如“第 2 关”“Level 2”“进入下一关”等。

推荐实现：

- 在第一关场景里加一个全屏 `CanvasLayer` 和 `ColorRect` 过渡层。
- 过渡层初始透明，不阻挡交互。
- 出口触发后，使用 `Tween` 或定时器把透明度从 `0` 平滑变到 `1`。
- 等过渡完成后调用 `get_tree().change_scene_to_file("res://scenes/level_2.tscn")`。
- 如果你想把当前 `main.tscn` 改名为 `level_1.tscn`，可以，但必须同步更新 `project.godot` 的主场景路径。否则不要随便改名。

过渡时长建议控制在 `0.6` 到 `1.0` 秒之间。不要让玩家卡在第一关结束状态里无法继续。

第二关不要再复用第一关的钥匙和教学障碍逻辑。

## 第二关玩法流程

关卡流程参考下面顺序：

1. 玩家进入第二关后，场景中已经有一个固定开关和一个可推动箱子。
2. 玩家按 `Space`，重力顺时针平滑旋转。
3. 重力切换后，玩家和箱子都要受新的重力影响，并自然掉落到新的地面。
4. 玩家推动箱子，让箱子接触到开关。
5. 箱子接触开关后，开关激活，出口从未激活状态变为激活状态。
6. 玩家再次按 `Space`，重力继续顺时针旋转。
7. 旋转结束后，玩家能够移动到激活出口处。
8. 玩家接触激活出口后，第二关过关。

注意：开关只能由箱子激活，不能由玩家直接踩到或碰到激活。

## 箱子实现要求

箱子需要同时满足两件事：

1. 会受当前重力影响下落。
2. 能被玩家推动。

推荐使用 `RigidBody2D` 实现箱子：

- 设置 `lock_rotation = true`，避免箱子被推动时旋转。
- 设置合适的 `mass`、`linear_damp` 和摩擦，让推动手感稳定。
- 设置 `can_sleep = false`，避免箱子在重力切换前进入休眠状态。
- 在 `_ready()` 和每次重力旋转结束后，把 `gravity_direction` 更新为 `GravityManager.current_gravity`。
- 让箱子监听 `GravityManager.rotation_finished`，不要在旋转动画中途提前切换重力。

不要用瞬移方式移动箱子。玩家推动箱子时，应该通过物理碰撞让箱子滑动或滚动，而不是直接改变它的坐标。

如果 `RigidBody2D` 在你的实现里很难控制，也可以改用受控的 `CharacterBody2D` 箱子，但它必须同样遵循当前重力、能被玩家推动，并且不会穿过墙壁或玩家。

## 开关和出口实现要求

开关建议使用 `Area2D`：

- 监听 `body_entered`。
- 只对 `body.is_in_group("push_box")` 的箱子生效。
- 玩家进入开关区域时不应触发开关。
- 开关激活后应保持激活状态，不要因为玩家离开就取消。

出口也建议使用 `Area2D`：

- 初始为未激活状态。
- 只有在开关激活后才允许触发过关。
- 出口只响应玩家，不响应箱子。
- 激活和未激活状态要靠颜色或简单形状区分，不要用文字说明。

## 关卡布局

请保证第二关的可解性：

- 玩家初始位置和箱子、开关不要重叠。
- 第一次 `Space` 旋转后，玩家和箱子应落到新的地面，并且玩家有空间推动箱子。
- 玩家推动箱子到开关处后，出口激活。
- 出口激活后，必须还需要一次 `Space` 旋转才能让玩家到达出口。
- 不要让玩家在开关激活前就能直接走到出口。
- 不要让玩家通过跳跃直接绕过推箱子步骤。
- 房间内要留有足够的水平空间，让玩家能沿当前屏幕左右方向推动箱子。

布局可以参考下面的逻辑关系，不需要完全照搬坐标：

```text
初始：玩家在房间一角，箱子和开关放在可推动路径上，出口未激活。
第一次旋转：玩家和箱子落到新的地面。
推箱子：箱子接触开关，出口激活。
第二次旋转：出口变成玩家可达。
接触出口：第二关过关。
```

## 视觉占位要求

继续使用简单占位视觉即可：

- 玩家：保持现有占位方块。
- 箱子：一个明显的矩形色块。
- 开关：一个和箱子颜色有区分的矩形或圆形色块。
- 出口：绿色或亮色矩形，未激活时用暗色或半透明表现。
- 过渡层：全屏黑色 `ColorRect`。

所有可交互对象继续保持 `Visual` 与碰撞节点分离。不要把美术样式硬编码在脚本里。

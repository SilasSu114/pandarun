# 第二关推箱子丝滑手感修复提示词

你是一个 Godot 4.7 游戏开发 Agent。请在 `projects/godot-gravity-tutorial-demo/` 项目中修复第二关推箱子的手感问题。当前推箱子不够丝滑，玩家贴身推动时会出现一顿一顿的感觉。

## 修改范围

只修改 `projects/godot-gravity-tutorial-demo/`。

重点文件：

```text
scripts/player.gd
scripts/push_box.gd
scenes/level_2.tscn
```

不要修改 `projects/godot-gravity-tutorial-demo-(4.3)/`。不要重做整个关卡，不要加入菜单、存档、音效或新美术资源。

## 当前问题定位

当前玩家和箱子都是 `CharacterBody2D`，并且箱子的移动是由玩家在 `move_and_slide()` 之后再手动调用 `push_from_player()` 驱动的。这个实现把“玩家移动”和“箱子移动”拆成了两次独立处理。

实际效果很容易变成：

1. 玩家先撞到箱子并被挡住。
2. 箱子再移动一点。
3. 下一帧玩家再撞上箱子。
4. 箱子又移动一点。

所以推起来会显得一顿一顿，不像两个物理体被同一个物理过程自然推开。

另外，箱子目前还有自己独立的重力移动和手动推动逻辑，两套位移叠加在一起也会加重卡顿感。

## 目标手感

修复后推箱子应该满足：

1. 玩家贴身推动箱子时，移动是连续的，没有明显停顿。
2. 玩家松开方向键后，箱子立刻停止。
3. 玩家离开箱子后，箱子不再自己滑行。
4. 箱子碰到墙或障碍物时立即停止。
5. 玩家不能穿过箱子。
6. 箱子不能闪现、吸附或穿墙。
7. 重力旋转后，这套手感仍然成立。

## 推荐修复方案

优先把 `PushBox` 从 `CharacterBody2D` 改成 `RigidBody2D`，让物理引擎统一处理玩家和箱子的接触。

推荐配置：

1. `lock_rotation = true`，避免箱子被推动时旋转。
2. `gravity_scale = 1.0`，让它继续受当前重力影响。
3. 根据当前 `GravityManager.current_gravity` 更新 `gravity_direction`。
4. 使用合理的 `mass`，不要过重导致玩家推不动，也不要过轻导致一碰就飞。
5. 使用 `linear_damp` 或物理材质摩擦，让玩家松手后箱子不会继续滑很远。
6. 如果使用物理材质，`friction` 应足够高，`bounce` 设为 `0`。

同时请减少或移除手动的 `push_from_player()` 位移逻辑：

1. 不要再用 `move_and_collide()` 驱动箱子。
2. 不要再用 `position += ...`、`global_position = ...` 或 `Tween` 移动箱子。
3. 玩家不要再把箱子当作一个独立移动的节点来控制。
4. 如果物理接触后推动力度仍不够，可以只在实际接触时给箱子一个很小的 `apply_central_force()` 或 `apply_central_impulse()`。
5. 这个附加力也必须来自玩家当前真实接触，而不是输入方向单独触发。

如果因为某些原因必须保留 `CharacterBody2D` 箱子，请改成“同一物理帧内联动”的方式：

1. 玩家在移动前先检测自己前方是否接触箱子。
2. 如果接触，则先让箱子移动一小段。
3. 再执行玩家的 `move_and_slide()`，让玩家贴上去。
4. 箱子的移动量必须与玩家本帧移动量保持一致。
5. 禁止箱子跨帧保存推动速度。

但首选方案仍然是 `RigidBody2D`，因为它更容易获得连续的物理推动手感。

## 需要避免的写法

请检查并避免：

1. 玩家 `move_and_slide()` 后再单独移动箱子。
2. 箱子内部保存 `_push_velocity` 并在下一帧继续使用。
3. 箱子移动速度快于玩家推动速度。
4. 用直接坐标赋值移动箱子。
5. 用 `Tween` 或协程把箱子推到某个目标点。
6. 用大范围检测区域代替真实接触。
7. 箱子松手后继续滑行很远。

## 碰撞与重力

请确认：

1. 玩家仍然被箱子阻挡。
2. 箱子仍然被墙、货架和边界阻挡。
3. 箱子不会被玩家穿透。
4. 箱子会跟随重力方向下落。
5. 重力旋转结束后，箱子的 `gravity_direction` 也更新为新方向。
6. 箱子在四个重力方向下都能被玩家自然推动。

## 开关流程

修复手感时不要破坏现有解谜流程：

1. 箱子必须仍然被推到开关位置。
2. `SwitchStopper` 或其他障碍物不能挡住箱子到达开关的路径。
3. 玩家不能直接触发开关。
4. 箱子接触开关后出口激活。
5. 出口激活后，再次旋转重力，玩家能到达出口并过关。

## 验收标准

请手动测试：

1. 玩家贴身推箱子时，箱子移动平滑连续。
2. 松开方向键，箱子立刻停止。
3. 玩家离开箱子，箱子不再自己移动。
4. 箱子撞墙后停止，不穿墙。
5. 箱子接触开关后激活出口，且不是突然吸附过去。
6. 在四个重力方向下，推箱子手感都正常。
7. 玩家不能穿过箱子。
8. 第二关仍然没有任何文字引导。

3. 物理参数如何调整。
4. 玩家与箱子之间的推动是如何传递的。
5. 手动测试结果。

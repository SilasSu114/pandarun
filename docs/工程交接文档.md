# 工程交接文档

## 1. 项目目标
本项目是 2D 平台跳跃游戏《熊猫卫士：逆转协议》的正式版。当前阶段的交付目标是：

1. 完成主菜单和第一关。
2. 主菜单要能正确跳转到第一关。
3. 第一关使用 PSD 素材的“高亮交互式元素”进行像素级复刻。
4. 只处理高亮交互式元素，其他非高亮元素不擅自替换。
5. 保持 Demo 作为隐藏彩蛋。
6. 后续继续对接第二关、第三关。

## 4. 关键决策与原因
1. 只处理第一关。
   - 用户明确要求不要看其他关卡。
2. PSD 3500x3500 作为像素级基准。
   - 目标游戏区域是 1080x1080。
   - 缩放系数：`1080 / 3500 = 0.308571`
3. PSD layer 1 作为背景。
   - 导出为 `assets/level1/background.png`
4. PSD layer 2 与 layer 1 的差分用于提取高亮交互元素。
   - 生成 10 个独立素材。
5. 高亮元素单独导出为透明 PNG。
   - 符合用户要求：“高亮显示的交互式元素。其他不要动。”
6. `level_1.tscn` 里的旧占位 ColorRect 部分替换为 Sprite2D。
   - 目前只替换了部分素材，未全部替换。
7. 主菜单 StartButton 已解锁。
   - 因为 `level_1.tscn` 已存在。
8. 保留四面墙。
   - 用户要求边框保留，防止玩家穿出画面。
9. `StartMarker` 保留。
   - 用户说左下灰色地带是出生点，但当前场景的 `StartMarker` 仍是绿色 START 标记。
   - 这不是高亮交互元素，所以未擅自替换。
10. Demo 彩蛋保留。
   - `main_menu.gd` 的 `DemoButton` 跳转到 `res://scenes/main.tscn`

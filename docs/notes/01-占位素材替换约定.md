# 占位素材替换约定

当前美术素材还没到位，可以先使用颜色块或简单几何体占位。请按“后续可直接替换素材”的方式组织节点：

1. 每个可交互对象都保持两层结构：
   - `Visual`：只负责显示占位颜色或图片。
   - `CollisionShape2D` 或其他碰撞节点：负责碰撞，不依赖视觉节点。
2. 不要在 `player.gd`、`main.gd`、`gravity_manager.gd` 里直接读取或修改 `ColorRect` 的颜色作为玩法逻辑。
3. 玩家、钥匙、出口等对象将来可以直接把 `Visual` 从 `ColorRect` 替换成 `Sprite2D` 或 `TextureRect`，不影响移动、旋转、碰撞和过关逻辑。
4. 占位对象的尺寸应尽量接近真实素材的预期比例，并让碰撞盒居中。
5. 不要把美术样式硬编码在脚本里。颜色只写在场景节点或导出属性上。
6. 后续替换素材时，只需要替换 `Visual` 节点或给 `Sprite2D`/`TextureRect` 指定新纹理，不应该需要重构关卡或玩法脚本。
